# Fontes embutidas

O build (`build.js`) coloca estas fontes dentro do `index.html` em base64 (no lugar de `/*FONTS*/`): o jogo não
depende do Google Fonts, funciona sem internet e não envia o endereço do jogador a terceiros.
São os arquivos variáveis do subconjunto latino (português incluído), baixados do Google Fonts.

| Arquivo | Família | Pesos | Licença |
| --- | --- | --- | --- |
| `orbitron.woff2` | Orbitron (The Orbitron Project Authors) | 400–900 | SIL Open Font License 1.1 |
| `inter.woff2` | Inter (The Inter Project Authors) | 300–900 | SIL Open Font License 1.1 |
| `jetbrains-mono.woff2` | JetBrains Mono (The JetBrains Mono Project Authors) | 400–700 | SIL Open Font License 1.1 |

O texto da licença está em `OFL.txt`.
